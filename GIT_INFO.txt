Git 명령어 참고
----------------------------------------
원격 저장소 정보 확인:
  git remote -v

현재 브랜치 확인:
  git branch

모든 브랜치 확인 (로컬 + 원격):
  git branch -a

원격 저장소에서 최신 변경사항 가져오기:
  git fetch origin

원격 저장소에서 최신 변경사항 가져오기 및 병합:
  git pull origin dev

로컬 변경사항을 원격 저장소에 푸시:
  git push origin dev
