# HowAboutThisWay Backend

## 프로젝트 소개

장애인과 교통약자를 위한 대중교통 경로 안내 서비스의 백엔드 API

## 기술 스택

- **Framework**: Spring Boot
- **Language**: Java
- **Database**: MySQL
- **ORM**: MyBatis
- **Build Tool**: Gradle

## 주요 기능

- 🚇 대중교통 경로 검색
- 🚶‍♂️ 보행자 경로 안내
- ♿ 교통약자 편의시설 정보
- 📍 POI 검색
- 🔐 OAuth 인증 (Google, Kakao)
- 📱 SMS 인증

## API 명세서

- "https://www.notion.so/HATW-API-222ba2fac10080089010f46c36c89aad?source=copy_link"

## 개발 환경 설정

1. `application.properties.example`을 `application.properties`로 복사
2. 필요한 API 키와 데이터베이스 설정 입력
3. `./gradlew bootRun`으로 실행
